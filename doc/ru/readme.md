# MacroJson

**MacroJson** - это header-only библиотека для чтения, записи и документирования JSON объектов на основе декларативного описания структуры данных. \
Библиотека позволяет автоматически генерировать следующее:
- Код C++ структуры
- JSON схему для документирования и валидации данных
- Функции для сериализации и десериализации JSON объектов

В качестве бэкэнда для работы с JSON данными используется библиотека RapidJSON.

## Какую проблему решает библиотека
При работе с JSON данными в C++ часто приходится писать дублирующийся код, имеющий идентичную семантику. Это привоит к дублированию логики, рассинхронизации между структурами данных, реализацией (де)сериализаторов и документации. **MacroJson** позволяет описать структуру данных **один раз** и автоматически генерировать весь остальной код. Это устранит дублирование, обеспечит согласованность между всеми компонентами и упростит поддержку кода.
