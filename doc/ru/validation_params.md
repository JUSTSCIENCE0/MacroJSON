# Описание параметров валидации

## Валидация строковых полей
### Регулярные выражения
Задать обязательное регулярное выражение для строки можно с помощью структуры `StringRegex`. Поле `pattern` должно содержать строку, представляющую регулярное выражение. При указании пустого регулярного выражения валидация по шаблону не будет проводиться и поле `pattern` будет опущено в сгенерированной JSON-схеме.
```cpp
struct StringRegex {
    std::string pattern = "";
};
```

### Длина строки
Минимальная и максимальная длина строки можно задать с помощью структуры `StringLength`. Поле `minLength` должно содержать минимальную длину строки, а поле `maxLength` - максимальную. Если значение поля равно `-1`, то соответствующая проверка не будет проводиться и поле будет опущено в сгенерированной JSON-схеме.
```cpp
struct StringLength {
    int minLength = -1;
    int maxLength = -1;
};
```

## Валидация числовых полей
### Кратность
Задать кратность числового поля можно с помощью структуры `MultipleOf`. Поле `multipleOf` должно содержать значение, кратное которому должно быть значение поля. Если значение поля равно `0`, то соответствующая проверка не будет проводиться и поле будет опущено в сгенерированной JSON-схеме.
```cpp
template<typename NUM,
            std::enable_if_t<std::is_arithmetic_v<NUM>, bool> = true>
struct MultipleOf {
    NUM multipleOf{};
};
```

### Минимальное и максимальное значение
Минимальное и максимальное значение числового поля можно задать с помощью структуры `Range`. Поля `minimum` и `maximum` должны содержать минимальное и максимальное допустимые значения соответственно. Поля `isExclusiveMinimum` и `isExclusiveMaximum` определяют, включают ли границы минимальное и максимальное значения в допустимый диапазон.
```cpp
template<typename NUM,
            std::enable_if_t<std::is_arithmetic_v<NUM>, bool> = true>
struct Range {
    NUM minimum = std::numeric_limits<NUM>::min();
    bool isExclusiveMinimum = false;
    NUM maximum = std::numeric_limits<NUM>::max();
    bool isExclusiveMaximum = false;
};
```

## Валидация массивов
Параметры валидации для массивов задаются с помощью структуры `ArrayParams`. Поля `minItems` и `maxItems` определяют минимальное и максимальное количество элементов в массиве. Поле `uniqueItems` указывает, должны ли элементы массива быть уникальными. \
Если поле `minItems` установлено в `0`, то массив может быть пустым. В таком случае поле `minItems` не будет включено в сгенерированную JSON-схему. \
Если поле `maxItems` установлено в `-1`, то максимальное количество элементов не ограничено. В таком случае поле `maxItems` не будет включено в сгенерированную JSON-схему. \
Если поле `uniqueItems` установлено в `false`, то элементы массива могут повторяться. В таком случае поле `uniqueItems` не будет включено в сгенерированную JSON-схему.

```cpp
struct ArrayParams {
    int minItems = 0;
    int maxItems = -1;
    bool uniqueItems = false;
};
```

**MacroJson** позволяет указывать параметры валидации для массива в целом и для типа элементов массива. В таком случае необходимо первым аргументом валидации указать `ArrayParams`, а далее - параметры валидации для типа элементов массива.\
Если не нужно валидировать параметры массива, то можно не указывать `ArrayParams`, а сразу передать параметры валидации для типа элементов массива.
