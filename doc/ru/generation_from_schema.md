# Генерация кода из JSON Schema (Beta)

    Внимание! Функциональность генерации кода из схемы находится на стадии разработки и не поддерживает все возможности JSON Schema.

Если уже имеется описание типов данных, с которыми вы работаете, в виде JSON Schema, то **MacroJson** позволяет автоматически генерировать C++ структуры и функции для (дe)сериализации на основе этой схемы. 

## Генератор

```cmake
macrojson_parse_schema(schema_file, output_file, create_objects)
```
schema_file - путь к файлу JSON Schema, который нужно обработать. \
output_file - имя выходного заголовочного файла, который будет сгенерирован. Сгенерированный файл будет создан в папке проекта в подпапке `generated`. Добавьте `generated` в исключения вашей системы контроля версий.\
create_objects - флаг, указывающий, нужно ли создавать объекты структуры данных. Если `TRUE`, то будут созданы объекты структуры данных, если `FALSE`, то только функции (де)сереализации и схемы.

Так же `macrojson_parse_schema` генерирует дополнительные вспомогательные header файлы в папке `generated`.

Для работы функции необходимо иметь установленный в системе интерпретатор Python 3.x. 

## Использование

Для использования генератора кода из JSON Schema необходимо выполнить следующие шаги:
0. Добавьте библиотеку MacroJson в ваш проект. 
1. В CMakeLists.txt вашего проекта добавьте следующий код для подключения CMake-генератора:

```cmake
# include header-generator
include(MacroJSON/cmake/HeaderGenerator.cmake)
```
2. В CMakeLists.txt вашего проекта вызовите функцию `macrojson_parse_schema()` для генерации заголовочного файла. Например:

```cmake
macrojson_parse_schema(
    person_schema.json
    person.hpp
    TRUE
)
```

3. Добавьте сгенерированный заголовочный файл в список исходных файлов вашего проекта. Например:

```cmake
# add executable
add_executable(my_app main.cpp generated/person.hpp)
```
