# Макросы

## Объект

### MJSON_OBJECT_BEGIN
Объявляет начало описания объекта. Должен быть вызван перед объявлением полей объекта.
Аргументы:
- name - имя объекта. Является идентификатором типа структуры, которая будет сгенерирована. Должно быть уникальным в рамках всего описания и соответствовать требованиям С/С++ к идентификаторам.
- def_title - заголовок объекта по умолчанию. Является строковым литералом, который будет использоваться в качестве поля `title` в JSON-схеме, если не указано другое значение при описании поля. Должно быть строковым литералом. Укажите `nullptr`, если не хотите использовать заголовок по умолчанию.
- def_description - описание объекта по умолчанию. Является строковым литералом, который будет использоваться в качестве поля `description` в JSON-схеме, если не указано другое значение при описании поля. Должно быть строковым литералом.  Укажите `nullptr`, если не хотите использовать описание по умолчанию.

### MJSON_FIELD
Объявляет поле объекта.
Аргументы:
- type - тип поля. Должен быть одним из поддерживаемых типов данных (см. [Поддерживаемые типы данных](supported_types.md)) или именем другого объекта, описанного выше по коду.
- name - имя поля. Является идентификатором, который будет использоваться в качестве имени поля в сгенерированной структуре и в JSON-схеме. Должно быть уникальным в рамках объекта и соответствовать требованиям С/С++ к идентификаторам.
- title - заголовок поля. Является строковым литералом, который будет использоваться в качестве поля `title` в JSON-схеме. Должно быть строковым литералом. Укажите `nullptr`, если не хотите использовать заголовок для этого поля или использовать заголовок объекта по умолчанию.
- description - описание поля. Является строковым литералом, который будет использоваться в качестве поля `description` в JSON-схеме. Должно быть строковым литералом. Укажите `nullptr`, если не хотите использовать описание для этого поля или использовать описание объекта по умолчанию.
- validation_params - параметры валидации поля. Является вариадическим списком аргументов, который может содержать ноль или более параметров валидации, применимых к этому полю. Каждый параметр валидации должен быть одним из поддерживаемых типов параметров валидации и быть согласованным с типом поля (см. [Параметры валидации](validation_params.md)).

### MJSON_OBJECT_END
Объявляет конец описания объекта. Должен быть вызван после объявления всех полей объекта.
Аргументы:
- name - имя объекта. Должно совпадать с именем, указанным в **MJSON_OBJECT_BEGIN** для этого объекта. Требования к аргументу аналогичны требованиям к аргументу name в **MJSON_OBJECT_BEGIN**.

## Перечисление

### MJSON_ENUM_BEGIN
Объявляет начало описания перечисления. Должен быть вызван перед объявлением значений перечисления.
Аргументы:
- name - имя перечисления. Является идентификатором типа перечисления, который будет сгенерирован. Должен быть уникальным в рамках всего описания и соответствовать требованиям С/С++ к идентификаторам.
- def_title - заголовок перечисления по умолчанию. Является строковым литералом, который будет использоваться в качестве поля `title` в JSON-схеме, если не указано другое значение при описании поля. Должно быть строковым литералом. Укажите `nullptr`, если не хотите использовать заголовок по умолчанию.
- def_description - описание перечисления по умолчанию. Является строковым литералом, который будет использоваться в качестве поля `description` в JSON-схеме, если не указано другое значение при описании поля. Должно быть строковым литералом.  Укажите `nullptr`, если не хотите использовать описание по умолчанию.

### MJSON_ENUM_UNIT
Объявляет элемент перечисления с автоматически вычисляемым значением.
Аргументы:
- name - имя элемента перечисления. Является идентификатором, который будет использоватьться в качестве имени элемента в сгенерированном перечислении. Должно быть уникальным в рамках перечисления и соответствовать требованиям С/С++ к идентификаторам.
- short_name - короткое имя элемента перечисления. Является значением строки, которое будет использоваться в качестве значения элемента в JSON.

### MJSON_ENUM_VALUE
Объявляет элемент перечисления с явно заданным значением.
Аргументы:
- name - имя элемента перечисления. Является идентификатором, который будет использоватьться в качестве имени элемента в сгенерированном перечислении. Должно быть уникальным в рамках перечисления и соответствовать требованиям С/С++ к идентификаторам.
- short_name - короткое имя элемента перечисления. Является значением строки, которое будет использоваться в качестве значения элемента в JSON.
- value - значение элемента перечисления. Является целочисленным литералом, который будет использоваться в качестве значения элемента в сгенерированном перечислении. Должно быть уникальным в рамках перечисления.

### MJSON_ENUM_ALIAS
Объявляет псевдоним элемента перечисления.
Аргументы:
- name - имя псевдонима. Является идентификатором, который будет использоватьться в качестве имени псевдонима в сгенерированном перечислении. Должно быть уникальным в рамках перечисления и соответствовать требованиям С/С++ к идентификаторам.
- short_name - короткое имя элемента перечисления. Является значением строки, которое будет использоваться в качестве значения элемента в JSON.
- value - имя или значение элемента перечисления, на которое ссылается псевдоним. Если указано имя элемента перечисления, оно должно быть идентификатором, который был объявлен ранее в этом же перечислении. Если указано значение элемента перечисления, оно должно быть целочисленным литералом, который соответствует значению одного из элементов перечисления, объявленных ранее в этом же перечислении.

### MJSON_ENUM_END
Объявляет конец описания перечисления. Должен быть вызван после объявления всех элементов перечисления.
Аргументы:
- name - имя перечисления. Должно совпадать с именем, указанным в **MJSON_ENUM_BEGIN** для этого перечисления. Требования к аргументу аналогичны требованиям к аргументу name в **MJSON_ENUM_BEGIN**.

## Полиморфный объект

Рекомендуется предварительно ознакомиться с концепцией полиморфных объектов и их поддержкой в **MacroJson** в разделе [Продвинутые возможности](advanced_features.md).

Для описания полиморфного объекта необходимо сначала, до вызова **MJSON_POLYMORPHIC_OBJECT_BEGIN** определить (`#define`) макрос `MJSON_BASE_OBJECT_NAME`, содержащий имя типа базового объекта. После завершения описания полиморфного объекта, после выхова **MJSON_POLYMORPHIC_OBJECT_END**, макрос `MJSON_BASE_OBJECT_NAME` нужно разопределить (`#undef`).

### MJSON_POLYMORPHIC_OBJECT_BEGIN
Объявляет начало описания полиморфного объекта. Должен быть вызван перед определением базового и всех производных объектов.
Аргументы:
- def_title - заголовок объекта по умолчанию. Является строковым литералом, который будет использоваться в качестве поля `title` в JSON-схеме, если не указано другое значение при описании поля. Должно быть строковым литералом. Укажите `nullptr`, если не хотите использовать заголовок по умолчанию.
- def_description - описание объекта по умолчанию. Является строковым литералом, который будет использоваться в качестве поля `description` в JSON-схеме, если не указано другое значение при описании поля. Должно быть строковым литералом.  Укажите `nullptr`, если не хотите использовать описание по умолчанию.

### MJSON_BASE_OBJECT_BEGIN
Объявляет начало описания базового объекта полиморфного объекта. Должен быть вызван после **MJSON_POLYMORPHIC_OBJECT_BEGIN** и перед объявлением производных объектов.
Аргументы:
- types_enum - имя перечисления, объявленного ранее, значение которого будет детерминировать конкретный тип производного объекта. Требования к аргументу аналогичны требованиям к аргументу name в **MJSON_ENUM_BEGIN**.

### MJSON_BASE_OBJECT_FIELD
Объявляет поле объекта базового типа полиморфного объекта.
Аргументы аналогичны аргументам макроса **MJSON_FIELD**.

### MJSON_BASE_OBJECT_END
Объявляет конец описания базового объекта полиморфного объекта. Должен быть вызван после объявления всех полей базового объекта и перед объявлением производных объектов.
Аргументы отсутствуют.

### MJSON_DERIVED_OBJECT_BEGIN
Объявляет начало описания производного объекта полиморфного объекта. Должен быть вызван после объявления базового объекта и перед объявлением полей производного объекта. Может быть вызван несколько раз для описания нескольких производных объектов.
Аргументы:
- name - имя производного объекта. Является идентификатором типа структуры, которая будет сгенерирована для этого производного объекта. Должно быть уникальным в рамках всего описания и соответствовать требованиям С/С++ к идентификаторам.
- type_enumerator - значение перечисления, объявленного ранее и используемого в базовом объекте, которое будет соответствовать этому производному объекту. Должно быть идентификатором, который был объявлен ранее в этом же перечислении.

### MJSON_DERIVED_OBJECT_FIELD
Объявляет поле объекта производного типа полиморфного объекта.
Аргументы аналогичны аргументам макроса **MJSON_FIELD**.

### MJSON_DERIVED_OBJECT_END
Объявляет конец описания производного объекта полиморфного объекта. Должен быть вызван после объявления всех полей производного объекта и перед объявлением следующего производного объекта или завершением описания полиморфного объекта.
Аргументы:
- name - имя производного объекта. Должно совпадать с именем, указанным в **MJSON_DERIVED_OBJECT_BEGIN** для этого производного объекта. Требования к аргументу аналогичны требованиям к аргументу name в **MJSON_DERIVED_OBJECT_BEGIN**.

### MJSON_POLYMORPHIC_OBJECT_END
Объявляет конец описания полиморфного объекта. Должен быть вызван после объявления всех производных объектов.
Аргументы отсутствуют.
